# Anito
This repository showcases my asset work on Anito, a pixel-art roguelike game inspired by Philippine mythology.

The project was built by a five-person team. My contribution was focused on visual asset production — including character, enemy, and tileset art created in Aseprite — along with some minor gameplay scripting in Unity.

Note: This repository only reflects my asset work on the project, not the full game codebase or contributions from the rest of the team.
